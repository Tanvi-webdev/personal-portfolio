## 🛠️ Technologies Used

- **HTML5** — Semantic website structure
- **CSS3** — Styling, responsive layouts, and animations
- **JavaScript** — Interactivity, form validation, and dynamic functionality

## ✨ Features

- Responsive design for desktop and mobile devices
- Navigation between Home, About, Skills, Projects, and Contact sections
- Mobile-friendly navigation menu
- Projects showcase
- Contact form with client-side validation
- Resume download link
- Scroll-based interactions and back-to-top functionality

1. Clone this repository:

   ```bash

   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension for local development.
